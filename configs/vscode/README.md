## Custom `settings.json` file from VSCode
`settings.json` is the primary configuration file in Visual Studio Code that stores user and workspace preferences in **JSON** format.  It allows for granular control over the editor's appearance, behavior, and extension settings that may not be available in the graphical UI.

### File Locations
- **User Settings**: Applies globally across all projects.
  - Windows: `%APPDATA%\Code\User\settings.json`
  - macOS: `$HOME/Library/Application Support/Code/User/settings.json`
  - Linux: `$HOME/.config/Code/User/settings.json`

- **Workspace Settings**: Applies only to the current project. Located in the .vscode directory within your project root (.vscode/settings.json).
